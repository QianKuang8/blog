# Learning list design decision

Question: How should the blog show the author's learning state?

Selected C: an independent learning list. Pending articles are expanded, completed and unmarked groups are collapsed. Articles entered from the list show the record at the bottom. Ordinary article lists keep their existing presentation. State is stored in Markdown and edited through GitHub; the prototype statuses are examples.

The HTML preserves the three alternatives for reference. It is throwaway comparison code, not production implementation.
